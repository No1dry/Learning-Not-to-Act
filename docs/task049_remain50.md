## Commands and streaming

The deployment-specific JSON/session and complete conda/python command live in
the local049 handoff. There are three explicit CLI operations:

~~~bash
python -u -m egrs.remain049 prepare --config CONFIG --output NEW_BANK
python -u -m egrs.remain049 run --config CONFIG --model base --output NEW_RUN/base
python -u -m egrs.remain049 run --config CONFIG --model h1 --output NEW_RUN/h1
python -u -m egrs.remain049 compare --base NEW_RUN/base --h1 NEW_RUN/h1 --output NEW_RUN/comparison.json
~~~

Preparation continuation is explicit `--continue`: verified ready sources are
reused, failed attempts are retained and not silently retried. Each model uses
one persistent subprocess VLA worker. Every completed episode saves raw query /
action evidence, immutable metadata, accepted-source archive and full MP4. It
then immediately runs the original binary mapping and prints task and overall
SR in percent plus completed/450. `progress.json` updates atomically per episode.
The final report must equal accumulated live outcomes. Its formal denominator
is450 only after complete valid execution. Technical failures stop the following
model and retain partial evidence; no overwrite/automatic rerun is supported.
