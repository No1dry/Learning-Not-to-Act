## 2. 单次VLA前向，语义上下文接入动作

每个当前观测只输入原双RGB、完整原指令和8维proprio。保留原OFT视觉、动作head、proprio projector和动作8×7/统计转换。语言q/k/v/o训练新r16/alpha32 LoRA；不继续035/036，不覆盖其权重。

一次原OFT前向取得：

- `H_a`：56×d动作隐藏；仍保留机器人、几何、双视角等控制信息。
- `H_v,H_l`：当前图像/原指令的prefix隐藏，排除BOS、proprio槽、动作占位和padding。使用实际插入布局/输入token映射，不用未核实的固定切片。
- `z = MLP_phi([mean(H_v),mean(H_l)])`：128维连续任务上下文，MLP隐藏256。它不是完整符号世界模型，也不保证数学意义的独立分解；prefix已融合proprio，去掉槽位不等于消除信息，只能由学习约束减少捷径。
- `H'_a = H_a + W_out SiLU(W_h LN(H_a) + W_z z + W_p p)`，瓶颈256，广播到56个位置。只把`W_out`零初始化，其他映射正常初始化。原冻结动作head读取`H'_a`。

另有3类软max辅助头预测**两个active任务目标已完成数量0/1/2**，只为z提供非恒定语义锚。不是NEED/PRESERVE实例头，不要求把两个相同壶人工绑定成A/B，不把其预测硬路由到动作或终止；连续z和控制特征仍须包含“具体哪个目标”的信息，计数本身不充分。两目标之外的保持条件K不是第三个计数标签。该设计不宣称解决任意01、隐物体或同类实例推理。

## 4. 损失与两组对照

原036主项保持：`L_main=.50 L_BC,10 + .25 L_ref,fresh + .25 L_ref,raw`。每更新仍12ten＋4fresh-ref＋4raw-ref，参考8次；前1/3/全轨迹各半。每更新另抽1个有效pair，按task→parent→variant分层，在原训练split内循环抽样；两组使用同序列。两端独立得到`(H_u,z_u,p_u,a_u*)`和`(H_v,z_v,p_v,a_v*)`。

记`D(H,z,p)`为新增残差＋原动作head，`ell`为按各自有效动作mask归一化的L1：

`L_self = 0.5 [ell(D(H_u,z_u,p_u),a_u*) + ell(D(H_v,z_v,p_v),a_v*)]`

`L_swap = 0.5 [ell(D(H_u,z_v,p_u),a_u*) + ell(D(H_v,z_u,p_v),a_v*)]`

`L_align = mean((normalize(z_u)-normalize(z_v))²)`（128维均值、epsilon=1e-6）。`L_count`为本更新已有fresh/ten样本及pair的计数CE，按出现的类分别平均再取均值，缺失标签不计；不额外加载观测。

- **C0**：`L_main + .10 L_count + .10 L_self`。
- **C1**：`L_main + .10 L_count + .10(.5 L_self+.5 L_swap) + .01 L_align`。

两组网络/参数量/语义标签/所有图像及动作相同，区别仅配对约束这一包。**绝不能用`a_u*=a_v*`作目标**。C1交换的是任务上下文，不交换接收端H/p/动作/相机，也不复制整条后半段动作。交换仅训练/dev；eval当前帧自己产生z，没有partner/GT/缓存示范。

这些系数是固定的首轮研究选择，不是从测试集调出来的。对照衡量整包约束，不能从两组分离声称align与swap各自有效；有价值再考虑消融，不预先加第三组。动作shortcut或恒定z仍可能存在：计数监督减轻恒定解但不证明策略依赖z，不能把结构图当因果证据。

## 5. 解释边界与可检验推论

令世界状态x、机器人状态r，任务目标事实为c(x,g)。在机器人重置不改变世界且目标不依赖机器人位姿的限定域，理想任务上下文满足`z*(x,r,g)=z*(x,r',g)`；但控制通常`a*(x,r,g)≠a*(x,r',g)`。这说明应对**子表示**而非整个策略施加不变约束。

一个基础捷径反例：若同一机器人状态r在两种场景中对应不同完成标签，任何只依赖r的确定性分类器无法同时零误差。这是说明性构造，非新定理/网络可识别或SR保证；实际数据是否完全共享r需另报告，不从rewind命名推断。

在观测歧义/遮挡下，两个等世界状态视角可具有不同信息量。`L_align/L_swap`因此只是软正则，可能损害可用证据；**不主张对观测后验严格等变或校准保证**。不把“允许简单观察/尝试”改成必须首步确定停止。当前无新探测技能、显式记忆或可见性oracle，保留这些限制。

只记录已有dev前向的计数准确率/类覆盖、pair距离、自用与交换动作L1，并在缓存H/z上做置零z的head-only诊断（不增加VLA前向）。若z扰动不影响动作，不能说模型通过z改变决策；若C1不优于C0，不为论文保留无效模块。

## 6. 与已查原始工作的关系

“学习不变表征”“忽略机械臂外观”本身不新：[MIR](https://arxiv.org/html/2103.09016v2)研究跨操作者视觉模仿；[Invariance Co-training](https://arxiv.org/html/2512.05230v1)用同状态的多观察条件进行表征对齐。这两项是直接近邻，不因我们换成OFT就消失。

[ReViP](https://arxiv.org/html/2601.16667v3)已经研究视觉/本体感觉失衡并注入阶段反馈；[RoCoDA](https://arxiv.org/html/2411.16959v2)已用局部因果结构做机器人增强；[LTL2Action](https://proceedings.mlr.press/v139/vaezipoor21a.html)已有任务剩余化；[CIVIL](https://civil2025.github.io/static/resources/CIVIL.pdf)借助教师给出的任务关键特征指导视觉模仿。不能把其中概念重新命名为首创。

**本候选要验证的具体差异**是：针对外部已完成子任务，以同世界/不同机器人起点的真实rewind配对，训练“任务上下文可交换，但动作必须跟随接收端重算”，并在严格成果保护的10与00能力保持上作同数据比较。它可能只是有效的任务针对性学习偏置；新颖性仍需实验和完整论文论证，未被本次检索证明。
