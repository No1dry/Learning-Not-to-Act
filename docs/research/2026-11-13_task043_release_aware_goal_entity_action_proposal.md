## 1. 决策与研究变量

推荐从当前042 F0完整末1000初始化两臂，保持其native路由，**不继续把TCIF设为必须有效的组件**。F0 10/00=68.89%/80%，F1=70%/80%且仅净增1条。F1全部权重保持为当前已测10最高候选，不自动改变服务器默认。

需要检验的不是“多加一个头是否提高accuracy”，而是：

**同一目标物体当前处于未达成、达成但未释放、达成且释放的哪一状态，是否应改变它对动作生成的影响；已成立关系能否同时作为动作上下文保留，而不被误当成仍需重复执行的目标。**

本轮只有同数据、同结构、同监督的G0/G1两臂，区别为**预测状态是否显式参与动作条件的聚合**；不把G1对旧F0的差值全算作该路由机制收益。

## 4. 目标编译与同类实例：不使用测试mask或隐藏ID

### 4.1 模型输入边界

线上仍只有两路当前RGB、完整原指令、8维原归一化proprio。不能传入task_key、initial_mask、source_id、真实goal/release、物体坐标、pair信息、未来帧或评测结果。

目标query仅由**当前完整指令的文本跨度**产生，复用同次OFT前向的指令hidden；不改写完整指令为“只做B”，不再调用VLM/LLM。

先实现明确有限的组合语法，覆盖现有九条指令：

- put both X and Y in/on Z：两个实体目标，关系和目的地跨度共享。
- put X ... and put Y ...：两个完整目标。不能按所有and分词，“yellow and white mug”必须保持一个实体短语。
- put X ... and close it：放置与关闭两个目标；it从同句明确先行词解析。
- turn on X and put Y on it：开关与放置两个目标。
- put both moka pots on the stove：一个同类目标组，基数2，不制造文本里不存在的pot_1/pot_2身份。

原九任务的训练事实按离线predicate语义绑定到上述文本目标；该映射只生产监督，不作为模型推理lookup/gate。运行期解析器只能接收instruction，不读data_scope/任务表猜哪一个已经完成。当前只承诺上述语法；不声称任意新自然语言都能解析。

### 4.2 实例集合

每个文本目标组g有m_g个实例query，当前总数最多2。独立文本目标m=1；同类双壶m=2，使用两个可学习slot seed+同一文本query，并共享所有后续头。slot不对应仿真对象编号。

训练时用组内最多2!种排列匹配**位置＋状态的标签集合**，同一匹配同时用于两种loss；不能状态匹配一套、坐标匹配另一套。匹配决定detach，loss对模型正常反向。集合聚合不含slot序号权重，禁止训练“slot0恒为A”。

这解决的是不可见ID的监督歧义，不保证RGB遮挡下实例可辨识或抓取一定成功。目标query/slot本身不是新发明。

## 5. 新监督：区分关系成立与释放

### 5.1 三状态，缺失不是第四个类别

对放置类目标，取同一当前帧的原生关系事实b与**该目标物体自己的**released：

| 条件 | 新状态标签 |
|---|---|
| b=False | U：关系未成立 |
| b=True且该物体released=False | H：关系成立但未释放 |
| b=True且该物体released=True | S：关系成立且已释放 |
| b未知，或b=True而release未知 | 该状态字段mask，不补标签 |

不以全场released代替某个物体released：例如机器人拿着B时，已经放好的A仍可为S。turn-on/close等非搬动物体目标只用其明确当前关系真值形成U/S，不凭空制造“夹着炉子”的H；不伪造缺失坐标。

S只表示**当前达成且释放**，不是永远不准改变的逻辑义务，更不是FINISH信号。抽屉/微波炉若需要先打开再放入再关，允许专家通过暂时改变已真关闭谓词来完成任务；不加禁止所有S→U的硬损失/控制锁。完整指令、当前动作hidden和BC仍学习依赖关系。

原count_label仍按旧定义保留；其关系计数可包含H，**不得断言S数量必须等于原count**。sidecar另存原relation_values以核对旧sum语义。

### 5.2 空间辅助标签

对位置可用的放置目标实体，使用同帧facts.objects[name].position和facts.tcp.position，二者均明确为world坐标，构造：

delta* = (object_position - tcp_position) / 1米。

仅用实际记录字段，不把归一化proprio当world坐标，不把controller TCP与测量grip site静默混用；语义/坐标frame不明确则只mask空间字段，原动作BC保留。不新增相机参数、分割器、bbox或几何渲染，也不把物体原点当成已证明的最佳抓取接触点。

同类壶标签为两个(position,status)的无序集合；位置来自训练审计，不是部署输入。空间监督只是定位辅助，不能承诺解决夹爪接触、拥挤炉面放置或碰撞规划。

## 6. 单次VLA前向中的动作接线

使用已验收F0 native有效SDPA合同，原56个shifted action hidden和原双RGB/指令布局保持，引用同一forward的visual/instruction hidden，不重复视觉编码或投影。

1. 文本目标跨度和slot seed，经共享128维cross-attention从visual hidden形成实体特征r_i。
2. 状态头预测p_i=(p_U,p_H,p_S)；几何头由r_i和当前proprio预测delta_hat_i。几何特征随接收端机器人状态重算，不强制rewind两端相等。
3. 实体动作条件e_i由r_i与**预测**delta_hat_i形成；非空间目标由文本语法确定的类型屏蔽几何分量，不用训练标签有效性mask改变actor。
4. 构造待处理上下文N和当前达成上下文K，送入新增动作残差：
   h' = h_base + W_out_goal SiLU(W_h h_base + W_N N + W_K K + W_p proprio)。
   h_base是原F0经过现有C1模块后的hidden，动作仍经原冻结OFT head输出8×7。
5. 仅新增W_out_goal零初始化，其余正常初始化；两臂update0动作等于同一个原F0，不能把全部新增层置零。原F0全部LoRA/z/residual/count完整复制，新模块同seed初始化。

全部actor条件都来自模型当前预测；GT状态/坐标/匹配只进入离线loss，不teacher-force状态gate、目标位置或实体选择。新模块可能被原h路径忽略，因此必须做下述匹配对照，不能用辅助准确率代替SR。

### G0/G1唯一研究差异

| 项目 | G0：同监督隐式条件对照 | G1：显式状态条件 |
|---|---|---|
| 文本query、实例slot、状态/定位头、参数量与loss | 相同 | 相同 |
| 位置与目标实体特征 | 都使用自己的预测 | 都使用自己的预测 |
| N/K权重 | 每个实体恒为1/2、1/2 | w_N=p_U+p_H；w_K=p_S |
| 其余VLA、数据、优化器/长度 | 相同 | 相同 |

上下文使用未归一化加权和除以固定实体数n：
N = sum_i w_N,i e_i / n；K = sum_i w_K,i e_i / n。
不要分别按sum(w)归一化：这会在仅一个实体时消掉状态幅度，让G1近似退化为G0。n来自指令结构，不是完成数量。

G0仍可从实体特征隐式推断状态，是强对照；G1并非获得更多真值。G1从动作loss反向进入预测状态，是否真正产生更好的动作由新正式SR检验。无argmax硬屏蔽、外部裁决或停止。

## 8. 与近邻及037的关系

- [ControlVLA](https://arxiv.org/html/2506.16211v1)：已有物体条件及零初始化适配分支。本轮不能以新增对象query/残差本身宣称首创；这里复用单VLA已有特征，用训练审计的状态与定位监督，不要求部署外部分割条件。
- [INDI / Act with Intent](https://arxiv.org/html/2608.23478v1)：已将行为意图蒸馏进入动作解码，并检验意图对动作的作用。043不用VLM解释未来执行视频生成意图，而用当前逐目标的关系/释放状态及实体位置；显式状态条件和“有相同辅助监督但无状态聚合”的对照是本轮可检验差异，不是已经证明的新学习原理。
- [AffordanceVLA](https://arxiv.org/abs/2606.06155)：已有Which/Where/How结构化感知—动作桥接及大规模辅助监督。043不复现其整套架构/大数据训练，只研究外部预完成后的剩余交互需求和当前成果上下文，仍须实验证明价值。
- 037 X审阅已指出同类实例、缺监督、目标依赖、latent不等于可观测信念、pair非识别定理。本提案正面采用实例集合匹配、仅现成当前字段、三状态释放定义、接收端几何、软条件而非硬保护；不是把037原稿直接改号上线。

候选研究贡献应围绕**外部完成改变目标实体的交互需求，而不等于从视觉场景删除该实体**，以及释放前后应产生不同动作需求。目标物体即使已完成，也可能仍是障碍/支撑关系的一部分，所以不抹除RGB、不硬清空已完成物体。仅仅“多加head、多训1000步”不构成贡献；G1−G0、错误类型/00保持是必要证据。

## 9. 可以成立的数学边界

1. 数量别名：两个不同目标的完成向量(1,0)与(0,1)计数同为1，但剩余目标不同，故单计数一般不能作为充分的目标状态。旧VLA仍有完整RGB/指令，不能由此证明旧z必然缺信息。
2. 集合对称：组内匹配和无序聚合对仿真实例重编号不变；不等于重新改写整条自然语言指令后VLA输出必然不变。
3. 同世界robot-rewind保持实体世界位置与目标语义，但改变TCP相对位置和正确动作；几何标签必须用接收端TCP重算，不施加完整动作不变。
4. 对独立合取目标，可用当前达成集描述剩余目标集；门/抽屉等有先决依赖，不能把所有当前真谓词永久删除或硬保护。S是当前事实，不是完整任务义务的证明。
5. RGB遮挡时监督是训练用潜态标签，预测只能反映观测可辨识性；不保证校准、可达性、无错抓或合规SR。当前不提出虚假的识别/安全/ICML理论保证。
