## A. 普通演示不足以区分目标判断和流程捷径：一个构造

考虑二元语义量c（A是否已完成）与机器人阶段量r（初始/交接姿态）。示范分布仅支持(c,r)=(0,0),(1,1)，目标动作类别分别是A、B。令`π_scene(c,r)=A if c=0 else B`，`π_phase(c,r)=A if r=0 else B`。

两策略在该示范分布上的分类BC风险均为0，但在合法外部完成状态(c,r)=(1,0)上分别选择B与A。因此该分布上的BC目标不能仅凭经验风险辨认这两个机制。

**证明**：逐一代入三个状态即可。若增加(1,0)→B训练约束，纯π_phase不再有零风险；但仍可能存在记住具体训练任务的第三个策略，不能由此推出跨任务泛化。

这是存在性例子，不是所有示范都严格满足c=r、所有VLA都只看姿态或所有BC必然失败。普通数据充分覆盖非相关状态、预训练先验或视觉本身已有辨识能力时，不适用“无法识别”的强结论。035/036只支持继续检验该解释，不能反过来当作其证明。

## B. 剩余目标与保护约束何时等价

设原最终目标为有限合取`G=P∪R`，P与R不交。在初态s，P已成立；两问题使用同一动力学/可用动作/剩余时域H/成功定义和约束K，并都将“轨迹期间保持P”列为约束，且问题可行：

- 原问题：在K与保持P下，最大化终态满足G的概率。
- 残差问题：在同样K与保持P下，最大化终态满足R的概率。

**命题**：两者可行策略集合和目标值相同，故最优策略集合相同。

**证明**：在任一可行轨迹上P从初态到终态恒真，终态满足G等价于终态满足R；其余条件相同。

这是明确问题语义的基础等价，不是复杂的新定理。它不适用于允许暂时破坏P再修复的原问题，也不保证两条有效运动在每一时刻动作相同。抽屉初始关闭不是“放碗之前就永久保护关屉”的依据；需用依赖/成果语义定义P。

## C. 完成干预是目标层的幂等更新，不是可逆几何变换

对相互独立、允许保持的目标i，定义抽象完成算子`C_i(R,P)=(R\{i},P∪{i})`。则：

1. `C_i∘C_i=C_i`（幂等）。
2. 对无依赖/不干涉的i,j，`C_i∘C_j=C_j∘C_i`（可交换）。
3. `C_i`一般不可逆，不构成SE(3)一类群；独立完成集合的并运算具有幂等可交换结构。

物理实现I_i应满足`φ(I_i(s),G)=C_i φ(s,G)`，其中φ是语义剩余/保护映射。只要求此关系在语义层成立，**不要求**两次物理搬运顺序得到完全相同坐标/速度、或物理操作可交换。依赖任务只在许可的顺序/状态域使用对应关系。

这给出候选学习关系：`φ_hat(o_i,G) ≈ C_i φ_hat(o,G)`，而非`π(o_i,G)=π(o,G)`。改变了目标完成事实，决策意图可以且应当改变；不变的是未受影响目标的角色。

## D. 一个有限的组合误差引理

把φ_hat表示为n个目标的NEED/PRESERVE概率向量，距离d取L1；C_i把第i个向量投影到PRESERVE而保留其他项，因此对d不扩张。考虑一个可行物理完成序列`I_i1,…,I_ik`。假设在**每个中间状态**都存在合法、决策相关状态对应的观测，且：

`d(φ_hat(o_j), C_ij φ_hat(o_{j-1})) ≤ ε_j`。

则由三角不等式与不扩张性：

`d(φ_hat(o_k), C_ik … C_i1 φ_hat(o_0)) ≤ Σ_j ε_j`。

若初始表示与真值误差≤δ，则末端表示对相应语义完成映射的误差≤δ+Σ_jε_j。证明是逐步插入`C_ij φ_hat(o_{j-1})`并递推；不依赖声称某具体网络已满足前提。

**关键限制**：单次训练样本上的小平均loss不保证未见中间状态的ε_j小；中间域覆盖/分布外误差仍需检验。不可观测状态可能无法满足该点态前提。引理只约束表示一致性，不保证动作可行、任务SR提高、零冗余/零破坏或无分布外失败。不能将它包装为无条件zero-shot保证。

## E. 从定义到可检验学习目标

1. 用A完成事实与机器人阶段解耦的配对检验A中的歧义，而不是只加更多普通轨迹。
2. 用B明确保护是约束/上下文，不能直接删除已完成对象视觉特征；不用错误动作逐点等同约束。
3. 用C约束“完成目标角色更新、无关目标角色不变”，并让这些角色实际影响action隐藏特征。
4. 同数据普通BC、角色引导无pair、完整pair三组区分数据收益与干预结构收益；若无增益则不支持必要性。
5. D提供未来多完成组合的条件性误差分析；现九任务两目标10不能验证所有组合，论文须区分理论定义域与实测范围。

## F. 部分可观测性与监督的诚实边界

部署用图像/本体估计角色，不读GT。已有仿真真值可以离线监督潜在状态概率，但该标签不是“人从该帧直接可见”的标注，不能要求不可观察状态被确定性识别；不确定时不能删除剩余义务。只有标签本身缺失/失配的监督项mask，不把旧未知/失败重写为真。

若两个场景产生完全相同可用观测，却需要不同动作，任何确定性当前帧策略都无法同时保证正确。当前数据未系统提供主动观察训练，不能以理论绕过这个信息限制。必要历史/主动感知可后续单独研究，不改变本轮二元评价、扩大benchmark或变成新增物理认证门槛。
